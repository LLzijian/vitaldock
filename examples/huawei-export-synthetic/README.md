# Synthetic Huawei-shaped export

Every value, device identifier and interval in this folder was invented for
VitalDock tests and demos. No real person, account or route is represented.

The three JSON files exercise health sample points, sport interval steps and
workout elapsed duration. Importing them should produce 11 normalized records
and two compatibility warnings: unverified distance/calorie units and preserved
HiTrack detail. There are two heart-rate records and one steps record with value 27.

This is a compatibility example, not a captured official Huawei response.
